# Outils de maintenance Services Micro

Exécutables **signés** des outils de maintenance de Services Micro. Les sources sont privées.

Chaque outil est publié sous deux étiquettes : `<outil>-vX.Y.Z` (permanente) et `<outil>-latest` (toujours la dernière version).
Une empreinte SHA-256 accompagne chaque exécutable.

|---|---|
| Ocelot Disk Lab | https://github.com/services-micro/sm-tools-releases/releases/download/ocelot-latest/ocelot.exe |

Toutes les versions : https://github.com/services-micro/sm-tools-releases/releases
